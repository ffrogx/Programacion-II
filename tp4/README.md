# TP4 - Asociacion, Agregacion y Composicion

Este proyecto implementa los 7 escenarios del Trabajo Practico 4:

1. Neobanco y billeteras globales
2. Plataforma de telemedicina
3. Logistica de tren azucarero
4. Motor de reservas para coworking
5. Gestion de E-Sports y torneos
6. Sistema de streaming por series
7. Planificacion academica universitaria

## Uso

Compilar:

    cd tp4
    mvn clean compile

Ejecutar un ejercicio:

    mvn exec:java -Dexec.mainClass="com.tp4.ejercicio1.Main1"

Reemplace `Main1` por `Main2`, `Main3`, ..., `Main7`.
